# Security policy

## Supported versions

The platform is pre-release and has no supported production version yet. This
section will be replaced with a version support table before the first release.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability, leaked credential,
private production context, or other sensitive report.

Use GitHub's private vulnerability reporting for this repository:

<https://github.com/DefinitelySecureStudio/platform/security/advisories/new>

Include the affected component and revision, reproduction steps, impact, and any
suggested mitigation. Remove real secrets, private lore, personal data, and
confidential production content from evidence whenever possible.

Maintainers will acknowledge a report as soon as practical, coordinate a fix,
and agree on disclosure timing with the reporter. Do not exploit the issue or
publish details before a remediation and disclosure plan is agreed.
